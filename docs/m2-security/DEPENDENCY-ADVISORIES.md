# M2-SEC-DEPS-01 — client production-dependency advisories

Evidence: `npm audit --omit=dev --json` (npm 10.9.9, Node 22.23.5) against `client/package-lock.json` at
`release/m2-rc1` 6119113 (byte-identical to `b4dc32d`, i.e. inherited, not introduced by any M2 lane). Raw outputs are in
this folder: `audit-before-omit-dev.json`, `audit-after-omit-dev.json`, `audit-after-including-dev.json`.

The lockfile was regenerated by npm itself in a package-enabled environment (the owner's linked machine, Linux VM) with
`--package-lock-only` and `npm_config_ignore_scripts=true` (no install scripts executed). Every package entry has
`resolved` and `integrity` from the registry; nothing was hand-edited. Commands:

```
npm uninstall zod resend mongodb --package-lock-only
npm install react-router-dom@^6.30.6 --package-lock-only
npm update lodash nanoid source-map-js postcss postcss-selector-parser --package-lock-only
```

Result: 9 version bumps (all within existing semver ranges), 19 packages removed, 0 added.
